# Portofolio Mufid Isnan Ardianto

Situs portofolio pribadi untuk memperkenalkan profil, keahlian, contoh proyek,
estimasi layanan, dan informasi kontak Mufid Isnan Ardianto. Proyek ini dibuat
menggunakan HTML dan CSS tanpa proses build atau dependensi tambahan.

## Halaman dan fitur

- `index.html` — halaman utama yang berisi Beranda, Tentang Saya, Keahlian,
  Galeri Proyek, Harga dan Jadwal, serta formulir kontak.
- `tentang.html` — profil lengkap yang berisi pendidikan, minat, teknologi yang
  dipelajari, prinsip belajar, dan tautan kontak.
- Navigasi pada halaman utama mengarah ke bagian yang sesuai. Tautan **Profil
  Lengkap** membuka halaman `tentang.html`.
- Galeri menampilkan enam contoh proyek. Saat ini semua contoh menggunakan
  gambar yang sama (`img/pict1.jpg`).

## Teknologi

- HTML5
- CSS3 (`css/style.css`)

## Struktur proyek

```text
.
├── index.html
├── tentang.html
├── css/
│   └── style.css
├── img/
│   ├── pict1.jpg
│   └── profil.jpg
└── README.md
```

## Menjalankan proyek

Tidak perlu instalasi atau proses build. Buka `index.html` langsung di browser.
Untuk pengalaman pengembangan lokal, proyek juga dapat dijalankan menggunakan
server statis seperti Live Server di Visual Studio Code.

Formulir kontak saat ini hanya berupa antarmuka HTML dan belum terhubung ke
backend atau layanan pengiriman email.
